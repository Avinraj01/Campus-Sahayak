# How to Successfully Register and Login

## Common Issue: "Email already registered"

This error occurs when you try to sign up with an email that's already in our system. Here are some solutions:

## Solution 1: Use a Different Email
Instead of using a common email like "test@example.com", try:
- yourname123@example.com
- myuniqueemail@example.com
- firstname.lastname@example.com

## Solution 2: If You Already Have an Account
If you've registered before, go to the Login tab instead of Sign Up.

## Successful Registration Example
1. Go to http://localhost:3000/login
2. Click "Sign Up" tab
3. Enter:
   - Full Name: Your Name
   - Email: youruniqueemail@example.com (make sure it's not in the list above)
   - Password: yourpassword123
   - User Type: Student (or Faculty/General)
4. Click "Sign Up"
5. You should be logged in automatically and redirected to the dashboard

## Successful Login Example
1. Go to http://localhost:3000/login
2. Click "Login" tab
3. Enter:
   - Email: youruniqueemail@example.com (the one you used to register)
   - Password: yourpassword123
   - User Type: Student (must match what you selected during registration)
4. Click "Login"
5. You should be redirected to the dashboard

## Troubleshooting Tips
- Make sure your email is not already in the system
- Ensure your password is correct
- Verify that the user type matches what you selected during registration
- Clear your browser cache if you're having persistent issues
